minisvg: I once paid for Adobe, then fell for open-source Inkscape, but at heart I've always loved lightweight tools, ideally ones that run right in the browser; now that AI is here, we can hand-craft the manual parts of our workflows exactly the way we want.

Shortcuts and tips

Select

Click
Select the shape, line, point or text under the pointer
Shift+click
Add to or remove from the selection
Drag on empty
Box select what lies wholly inside; Shift adds to the selection
Ctrl+click
Select the whole group it belongs to, such as a panel or an imported figure
Esc
Select the group around the selection, one level up each time, then deselect
Ctrl+A
Select all in the current group; Ctrl+Shift+A deselects

Move and resize

Drag
Move; dragging any part of a selected group, or the dot at its centre, moves the group; Shift keeps it to 45° steps; edges and centers snap to the page and to nearby objects, Ctrl turns snapping off
Alt+drag
Move a copy; Ctrl+D then repeats the copy and move
← ↑ → ↓
Nudge 0.1 mm; with Shift 1 mm
Corner handle
Scale in proportion; Shift scales freely. Click a corner to switch to skew (orange diamonds): drag a corner and the opposite one stays put, Shift keeps it to one direction; click again to scale
Side handle
Stretch one side; on text, the left or right handle re-wraps the text at that width with the font size unchanged
Rotate handle
Rotate; Shift snaps to 15°
Round handle
Round the corners of a rectangle
End handle
Move an end of a line or arrow; Shift snaps to 45°
Right panel
Exact X, Y, W, H (mm) and rotation

View

Wheel
Scroll; Shift+wheel scrolls sideways
Ctrl+wheel
Zoom (or pinch)
Space+drag
Pan (or drag with the middle button)
Ctrl+0
Fit the page to the window; Ctrl+1 actual size, Ctrl+= Ctrl+- zoom in and out
Ctrl+R
Rulers; Ctrl+' grid
?
This help

Draw

V
Select tool (also Esc)
T
Text: click to type, or click a text to edit it
M
Rectangle
L
Ellipse
\
Line
A
Arrow (activation)
B
Inhibition (blunt end); Head in the Appearance panel resizes arrowheads and blunt ends, and new ones use the last size
Shift+drag
Square, circle, or a line in 45° steps
I
Eyedropper: click an object to give the selected objects its style; Alt+click applies the picked style to an object
Fill and stroke
The two swatches under the tools colour the selection, or new shapes when nothing is selected; Shift+X swaps fill and stroke, D sets no fill and a black stroke
C
Crop a photo: drag across it; drag again to change the crop, or past its edges to remove it

Text

Double-click
Edit in place; Esc finishes and returns to the Select tool (Ctrl+Z undoes the edit), Enter starts a new line
X² X₂
Superscript or subscript the characters selected while editing; Ctrl+Shift+= and Ctrl+Alt+Shift+= do the same
Ctrl+Shift+.
Font size up 1 pt; Ctrl+Shift+, down
Part of a text
While editing, select characters, then change Size, Font, Color, B or I in the Text panel to restyle only them
Left/Center/Right
Anchor the selected text; lines align left, center or right and the text keeps its place
Text panel
Font, size (pt), colour, bold and italic of the selected text; the Font list also offers the fonts on this computer: all of them in Chrome and Edge (the browser asks once), the common ones that are installed elsewhere

SVG Chat

AI settings
Your own API key for GLM or DeepSeek
Enter
Send; Shift+Enter for a new line
Attach
A text file to draw from, or an image to redraw; paste or drop works too
Selection
Select part of the figure first to ask about it or have it changed in place

File

Ctrl+O
Open an SVG (a PNG or JPG is placed on the canvas)
Ctrl+Shift+P
Place (import) an SVG, PNG or JPG into this canvas; Ctrl+I also works
Ctrl+S
Export SVG as name_YYMMDD_HHMMSS.svg; after the first save it writes back to the same file; Ctrl+Shift+S picks a new file
Ctrl+P
Vector PDF through the print dialog
Drop a file
An SVG opens or is imported; a PNG or JPG is placed where dropped
File menu
PNG at 300 or 600 dpi; vector PDF through the print dialog (best in Chrome or Edge)

Edit

Ctrl+Z
Undo
Ctrl+Shift+Z
Redo (or Ctrl+Y)
Ctrl+C
Copy
Ctrl+X
Cut
Ctrl+V
Paste what was copied last: objects, or an image; SVG text from another app is imported
Ctrl+F
Paste in front of the selection, where it was copied; Ctrl+B behind it, Ctrl+Shift+V on top
Ctrl+D
Transform again: repeat the last move, scale or rotation
Delete
Delete
Copy style
Edit menu, or use the eyedropper (I)
Select menu
All, all text, or every shape or text with the same fill or stroke

Ctrl+Shift+]
