minisvg: I once paid for Adobe, then fell for open-source Inkscape, but at heart I've always loved lightweight tools, ideally ones that run right in the browser; now that AI is here, we can hand-craft the manual parts of our workflows exactly the way we want.

Shortcuts and tips

Select

Click
Select an object (its whole group)
Shift+click
Add to or remove from the selection
Drag on empty
Box select; Shift adds to the selection
Double-click
Enter a group; on text, edit it
Ctrl+click
Pick an object inside a group directly
Ctrl+A
Select all in the current group
Esc
Up one group level, then deselect

Move and resize

Drag
Move; Ctrl keeps it horizontal or vertical
← ↑ → ↓
Nudge 0.1 mm; with Shift 1 mm
Corner handle
Scale in proportion; Shift scales freely
Side handle
Stretch one side
Rotate handle
Rotate; Ctrl snaps to 15°
Round handle
Round the corners of a rectangle
End handle
Move an end of a line or arrow; Shift snaps to 45°
Right panel
Exact X, Y, W, H (mm) and rotation

View

Wheel
Scroll; Shift+wheel scrolls sideways
Ctrl+wheel
Zoom (or pinch)
Space+drag
Pan (or drag with the middle button)
5
Fit the page to the window
?
This help

Draw

V
Select tool (also Esc)
T
Text: click to type, or click a text to edit it
R
Rectangle
E
Ellipse
L
Line
A
Arrow (activation)
I
Inhibition (blunt end)
Shift+drag
Square, circle, or a line in 45° steps
Panel labels
Label the selected panels A, B, C… at their top-left; the box under the button sets the next letter

Text

Double-click
Edit in place; Enter finishes, Esc cancels
Shift+Enter
New line while editing
X² X₂
Superscript or subscript the characters selected while editing
Text panel
Font, size (pt), colour, bold and italic of the selected text

SVG Chat

AI settings
Your own API key for GLM or DeepSeek
Enter
Send; Shift+Enter for a new line
Attach
A text file to draw from, or an image to redraw (needs glm-5.3-flash or deepseek-flash); paste or drop works too
Selection
Select part of the figure first to ask about it or have it changed in place

File

Ctrl+O
Open an SVG (a PNG or JPG is placed on the canvas)
Ctrl+I
Import an SVG, PNG or JPG into this canvas
Ctrl+S
Export SVG as name_YYMMDD.svg
Drop a file
An SVG opens or is imported; a PNG or JPG is placed where dropped
File menu
PNG at 300 or 600 dpi; vector PDF through the print dialog (best in Chrome or Edge)
